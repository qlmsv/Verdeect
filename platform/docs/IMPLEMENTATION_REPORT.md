# Проверки при переносе M0.1 в GitHub

Дата: 2026-09-14. Источник: `VERDEECT_Platform_M0.1_source.zip`, повторная распаковка и выполнение проверок в рабочем контейнере.

| Проверка | Результат |
| --- | --- |
| `python -m pytest -q` | 68 passed |
| `npm run test:sdk` | TypeScript compile, 16 passed |
| `python scripts/smoke_local.py` | 8 HTTP-проверок, passed |

HTTP smoke запускает два независимых UVicorn-процесса на loopback-портах и подтверждает: запуск процессов, отказ анонимному запросу, серверную сессию и организацию, передачу подписанных полномочий BFF в metering, идемпотентность показаний, отказ без CSRF, отказ прямому metering-запросу без токена и аннулирование платформенной сессии.

Все 53 файла исходного кода, инфраструктуры и тестов сопоставлены с архивом по содержимому Git tree. Первоначально обнаруженное различие заключалось только в завершающем переводе строки `upstream.lock.json`; оно исправлено перед коммитом. README и документы адаптированы для каталога `platform/`.

Не проверялись: полный OpenWebUI frontend/backend, настоящие Svelte-страницы в браузере, Docker, живой Keycloak, общее SSO и глобальный выход, React fixture в браузере, Twenty, production-развёртывание и восстановление.

OIDC-тесты подменяют проверенный ответ IdP. Тесты overlay используют маленький синтетический репозиторий. SDK-тесты используют синтетические DOM-объекты. Эти результаты не следует выдавать за сквозную проверку всей платформы.

Отчёт фиксирует локальные проверки. Результат GitHub Actions определяется отдельно по конкретному запуску workflow.
